# Example configurations

The app's configuration as IoT Open stores it (the keys of `app.json`). Output ids, groups and sound files are
examples. The functions are chosen in the form (`watch`, function ids are examples); the app writes `toolong.group`,
`toolong.label` and `toolong.sound` on them. Functions already tagged with `toolong.group` are watched too, and
show up in the form.
